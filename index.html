Sobre a disciplina

A disciplina de Estrutura de Dados I tem como finalidade desenvolver conhecimentos e habilidades fundamentais para a organização, o armazenamento, o acesso e a manipulação eficiente de dados em programas computacionais.

Ao longo da disciplina, os estudantes irão explorar diferentes estruturas de dados, utilizando a linguagem de programação C para compreender como os dados são organizados na memória e como os algoritmos podem ser desenvolvidos para resolver problemas computacionais de maneira eficiente.

O estudo envolve desde conceitos fundamentais, como ponteiros, registros e alocação dinâmica de memória, até estruturas mais elaboradas, como listas encadeadas, pilhas e filas, além de algoritmos de pesquisa e ordenação.
