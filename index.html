SOBRE A DISCIPLINA

Uma base sólida para programar melhor.

Compreender estruturas de dados é aprender a organizar informações e escolher maneiras adequadas de resolver problemas computacionais.

A disciplina de Estrutura de Dados I desenvolve conhecimentos e habilidades fundamentais para a organização, o armazenamento, o acesso e a manipulação eficiente de dados em programas computacionais.

Ao longo dos estudos, você utilizará a linguagem C para compreender como os dados são organizados na memória e como os algoritmos podem ser construídos para resolver problemas de maneira clara e eficiente.

O percurso inclui conceitos como ponteiros, registros e alocação dinâmica de memória, além de estruturas como listas encadeadas, pilhas e filas. Também serão explorados algoritmos de pesquisa e ordenação.

Mais do que conhecer estruturas, o objetivo é saber quando e como utilizá-las.
