FUNDAMENTOS

1. O que é Estrutura de Dados?

Estrutura de Dados é uma área da computação que estuda maneiras de organizar, armazenar e manipular dados para que possam ser utilizados de forma eficiente pelos programas.

Durante o desenvolvimento de um software, precisamos trabalhar com diferentes informações, como nomes, idades, notas, produtos e registros.

As estruturas de dados permitem organizar essas informações de acordo com as necessidades de cada aplicação.

APLICAÇÕES

2. Por que estudar Estrutura de Dados?

A escolha adequada de uma estrutura de dados pode tornar um programa mais organizado, eficiente e fácil de manter.

Organização

Permite organizar informações de maneira lógica e estruturada.

Eficiência

Ajuda a melhorar o desempenho das operações realizadas pelos programas.

Reutilização

Facilita a construção de soluções que podem ser utilizadas em diferentes aplicações.

ORGANIZAÇÃO DOS DADOS

3. Classificação das Estruturas de Dados

As estruturas de dados podem ser classificadas de diferentes maneiras. Uma classificação inicial considera a forma como os dados são organizados e armazenados.

3.1 Estruturas estáticas

Possuem tamanho definido previamente, geralmente durante a declaração.

Exemplo: vetores em linguagem C.

3.2 Estruturas dinâmicas

Permitem alocação e liberação de memória durante a execução do programa, possibilitando maior flexibilidade na organização dos dados.

Exemplo: listas encadeadas.

3.3 Organização dos dados

Também podemos estudar estruturas lineares, nas quais os elementos seguem uma sequência, e estruturas não lineares, que apresentam relações mais complexas entre seus elementos.

APRENDENDO NA PRÁTICA

4. Exemplo prático em linguagem C

Imagine que precisamos armazenar as notas de cinco alunos.

Uma possibilidade é utilizar um vetor, que permite armazenar vários valores do mesmo tipo em uma única estrutura.

Exemplo: armazenamento de notas

#include <stdio.h>

int main() {

    float notas[5];

    for (int i = 0; i < 5; i++) {

        printf("Digite a nota do aluno: ");
        scanf("%f", &notas[i]);

    }

    printf("\nNotas cadastradas:\n");

    for (int i = 0; i < 5; i++) {

        printf("%.2f\n", notas[i]);

    }

    return 0;
}

Nesse exemplo, utilizamos um vetor chamado notas, capaz de armazenar cinco valores do tipo float.

Observe que os elementos são acessados por meio de índices, começando em zero.
