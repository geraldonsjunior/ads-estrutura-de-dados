FUNDAMENTOS

1. O que são listas?

Uma lista é uma estrutura de dados que organiza elementos em uma sequência. Cada elemento ocupa uma posição lógica dentro dessa sequência.

Os elementos podem ser números, nomes, produtos, notas de estudantes ou qualquer outro tipo de informação.

Exemplo de uma lista de números:

10 - 20 - 30 - 40 - 50

Nesse exemplo, temos uma lista contendo cinco elementos inteiros organizados em sequência.

Exemplo de aplicação:

Imagine um sistema acadêmico que precisa armazenar os nomes dos estudantes matriculados em uma turma. Uma lista pode organizar esses nomes e permitir a inclusão ou exclusão de estudantes.

ABSTRAÇÃO DE DADOS

2. Listas e Tipos Abstratos de Dados (TAD)

Uma lista também pode ser compreendida como um Tipo Abstrato de Dados (TAD).

Nesse contexto, definimos quais operações podem ser realizadas sobre a lista, sem necessariamente expor os detalhes internos de sua implementação.

Operações fundamentais:

Criar

Inicializar uma lista vazia.

Inserir

Adicionar um elemento à lista.

Remover

Retirar um elemento da lista.

Consultar

Localizar um elemento.

Listar

Apresentar todos os elementos.

Verificar

Identificar se a lista está vazia ou cheia.

O TAD define o comportamento esperado da lista. A implementação pode utilizar vetores ou ponteiros, por exemplo.

IMPLEMENTAÇÕES

3. Formas de implementação de listas

Existem diferentes maneiras de implementar uma lista. Nesta disciplina, estudaremos principalmente:

3.1 Lista sequencial

Armazena os elementos em posições consecutivas de memória, normalmente utilizando um vetor.

3.2 Lista simplesmente encadeada

Organiza os elementos por meio de nós. Cada nó armazena um dado e um ponteiro para o próximo nó.

3.3 Lista duplamente encadeada

Cada nó possui dois ponteiros: um para o próximo elemento e outro para o elemento anterior.

3.4 Lista circular

O último elemento aponta novamente para o primeiro, formando uma estrutura circular.

IMPLEMENTAÇÃO COM VETORES

4. Listas sequenciais

Uma lista sequencial utiliza um vetor para armazenar os elementos. Sua capacidade normalmente é definida durante a declaração da estrutura.

Exemplo em C:

#include <stdio.h>

#define MAX 5

int main() {

    int lista[MAX] = {10, 20, 30, 40, 50};

    for (int i = 0; i < MAX; i++) {

        printf("Posicao %d: %d\n", i, lista[i]);

    }

    return 0;
}

O vetor armazena cinco elementos. Cada elemento pode ser acessado diretamente por meio de seu índice.

Representação:

Indice:      0    1    2    3    4
Elemento:   10   20   30   40   50

O primeiro elemento ocupa o índice zero e o último ocupa o índice quatro.

MANIPULAÇÃO DE ELEMENTOS

5. Operações em listas sequenciais

5.1 Inserção de elementos

A inserção consiste em adicionar um novo elemento à lista. Quando a inserção ocorre em uma posição intermediária, precisamos deslocar os elementos seguintes para abrir espaço.

Exemplo:

Lista inicial:

10 - 20 - 40 - 50

Inserindo o valor 30 na posição 2:

10 - 20 - 30 - 40 - 50

5.2 Remoção de elementos

A remoção consiste em retirar um elemento da lista. Em uma implementação sequencial, os elementos posteriores precisam ser deslocados para ocupar a posição liberada.

Exemplo:

Lista inicial:

10 - 20 - 30 - 40 - 50

Removendo o valor 30:

10 - 20 - 40 - 50

5.3 Consulta de elementos

A consulta permite localizar um elemento na lista e verificar sua posição. 

int valor = 30;

for (int i = 0; i < quantidade; i++) {

    if (lista[i] == valor) {
        printf("Elemento encontrado na posicao %d", i);
    }

}
PROGRAMAÇÃO EM C

6. Implementando uma lista sequencial em C

Vamos desenvolver uma implementação simples de lista sequencial com operações de inserção, exclusão e listagem.

Exemplo completo:

#include <stdio.h>

#define MAX 10

int lista[MAX];
int quantidade = 0;

void inserir(int valor) {

    if (quantidade < MAX) {

        lista[quantidade] = valor;
        quantidade++;

        printf("Elemento inserido!\n");

    } else {

        printf("Lista cheia!\n");

    }
}

void listar() {

    if (quantidade == 0) {

        printf("Lista vazia!\n");

    } else {

        for (int i = 0; i < quantidade; i++) {

            printf("%d ", lista[i]);

        }

        printf("\n");
    }
}

void excluir(int valor) {

    int posicao = -1;

    for (int i = 0; i < quantidade; i++) {

        if (lista[i] == valor) {
            posicao = i;
            break;
        }

    }

    if (posicao == -1) {

        printf("Elemento nao encontrado!\n");

    } else {

        for (int i = posicao; i < quantidade - 1; i++) {

            lista[i] = lista[i + 1];

        }

        quantidade--;

        printf("Elemento removido!\n");

    }
}

int main() {

    inserir(10);
    inserir(20);
    inserir(30);

    printf("Lista atual: ");
    listar();

    excluir(20);

    printf("Lista apos exclusao: ");
    listar();

    return 0;
}

Nesse exemplo, utilizamos um vetor para armazenar os elementos e uma variável chamada quantidade para controlar quantos elementos estão atualmente armazenados.

A função inserir() adiciona um elemento ao final da lista, enquanto excluir() procura um valor e remove sua ocorrência.

PONTEIROS E MEMÓRIA

7. Listas simplesmente encadeadas

Uma lista simplesmente encadeada é composta por elementos chamados nós.

Cada nó possui duas partes:

Dado

Informação armazenada no nó.

Ponteiro

Endereço do próximo nó da lista.

Estrutura de um nó em C:

typedef struct No {

    int valor;

    struct No *proximo;

} No;

O campo valor armazena o dado, enquanto proximo guarda o endereço do próximo nó.

Representação de uma lista encadeada:

Inicio
  |
  v
[10 | *] -> [20 | *] -> [30 | NULL]

O último nó aponta para NULL, indicando que não existe outro elemento depois dele.

ALOCAÇÃO DINÂMICA

8. Exemplo de inserção em lista encadeada

Para inserir um elemento no início de uma lista simplesmente encadeada, criamos um novo nó e ajustamos os ponteiros. 

#include <stdio.h>
#include <stdlib.h>

typedef struct No {

    int valor;
    struct No *proximo;

} No;

void inserirInicio(No **inicio, int valor) {

    No *novo = malloc(sizeof(No));

    if (novo == NULL) {
        printf("Erro ao alocar memoria!\n");
        return;
    }

    novo->valor = valor;
    novo->proximo = *inicio;

    *inicio = novo;
}

void listar(No *inicio) {

    No *atual = inicio;

    while (atual != NULL) {

        printf("%d -> ", atual->valor);

        atual = atual->proximo;

    }

    printf("NULL\n");
}

void liberarLista(No *inicio) {

    while (inicio != NULL) {

        No *auxiliar = inicio;

        inicio = inicio->proximo;

        free(auxiliar);

    }
}

int main() {

    No *inicio = NULL;

    inserirInicio(&inicio, 30);
    inserirInicio(&inicio, 20);
    inserirInicio(&inicio, 10);

    listar(inicio);

    liberarLista(inicio);

    return 0;
}

Resultado esperado:

10 -> 20 -> 30 -> NULL

Observe que a função recebe o endereço do ponteiro inicial para poder modificar o início da lista.

ANÁLISE COMPARATIVA

9. Comparação entre listas sequenciais e encadeadas

Lista sequencial

  • Utiliza vetor.
  • Armazenamento contíguo.
  • Acesso direto por índice.
  • Capacidade normalmente fixa.
  • Inserções e remoções intermediárias exigem deslocamentos.

Lista encadeada

  • Utiliza nós e ponteiros.
  • Não exige memória contígua.
  • O acesso é feito percorrendo os nós.
  • Pode crescer dinamicamente.
  • Inserções e remoções podem ser realizadas ajustando ponteiros.
ANÁLISE DE ALGORITMOS

10. Noções de complexidade das operações

A complexidade permite analisar como o custo de uma operação varia conforme a quantidade de elementos armazenados.

Considerando as implementações apresentadas, temos as seguintes situações:

O(1)

Acesso por índice em uma lista sequencial.

O(n)

Busca por valor em lista sequencial e acesso a uma posição em lista encadeada.

O(1)

Inserção no início de uma lista encadeada.

A complexidade de inserções e remoções depende da posição da operação e de como a lista está implementada.
