Início Introdução Ponteiros

Unidade 2 — Ponteiros em C

Nesta unidade, vamos estudar os ponteiros, um dos conceitos fundamentais da linguagem C e da disciplina Estrutura de Dados.

Você aprenderá como acessar endereços de memória, armazenar esses endereços em variáveis e manipular valores utilizando ponteiros.

1. O que são ponteiros?

Um ponteiro é uma variável que armazena o endereço de memória de outra variável.

Normalmente, uma variável guarda um valor. Já um ponteiro guarda o endereço onde determinado valor está armazenado.

Exemplo:

int idade = 25;

int *ponteiro = &idade;

Observe o significado:

  • idade: variável que armazena o valor 25.
  • &idade: endereço de memória da variável idade.
  • ponteiro: variável que armazena esse endereço.
  • *ponteiro: valor armazenado no endereço apontado.

2. Endereço de memória

Cada variável ocupa uma região da memória do computador. Essa região possui um endereço que permite localizar onde o dado está armazenado.

Na linguagem C, utilizamos o operador & para obter o endereço de uma variável.

Exemplo prático:

#include <stdio.h>

int main() {

    int numero = 10;

    printf("Valor: %d\n", numero);
    printf("Endereco: %p\n", (void *)&numero);

    return 0;
}

A saída mostrará o valor da variável e seu endereço de memória. O endereço apresentado será diferente em cada execução ou ambiente.

3. Declarando um ponteiro

Para declarar um ponteiro, utilizamos o operador * junto ao tipo de dado. 

int *p;
float *p;
char *p;

O tipo do ponteiro indica o tipo de dado que ele deverá apontar.

  • int *p: ponteiro para inteiro.
  • float *p: ponteiro para número real.
  • char *p: ponteiro para caractere.

É uma boa prática inicializar os ponteiros. Quando ainda não apontam para uma variável, podemos utilizar NULL: 

int *p = NULL;

4. Os operadores & e *

Dois operadores são essenciais para compreender ponteiros:

  • & (endereço): obtém o endereço de memória de uma variável.
  • * (desreferenciação): acessa o valor armazenado no endereço apontado.

Exemplo:

#include <stdio.h>

int main() {

    int numero = 50;

    int *p = &numero;

    printf("Valor de numero: %d\n", numero);
    printf("Endereco de numero: %p\n", (void *)&numero);
    printf("Endereco armazenado em p: %p\n", (void *)p);
    printf("Valor apontado por p: %d\n", *p);

    return 0;
}

Observe que o endereço de numero é armazenado em p. Ao utilizar *p, acessamos o valor 50.

5. Modificando uma variável através de um ponteiro

Um ponteiro também permite alterar o valor de uma variável sem acessá-la diretamente pelo seu nome.

Exemplo:

#include <stdio.h>

int main() {

    int numero = 10;

    int *p = &numero;

    printf("Antes: %d\n", numero);

    *p = 100;

    printf("Depois: %d\n", numero);

    return 0;
}

Resultado: 

Antes: 10
Depois: 100

Quando executamos *p = 100, alteramos diretamente o conteúdo da variável apontada pelo ponteiro.

6. Ponteiros e funções

Podemos utilizar ponteiros para permitir que uma função modifique uma variável recebida como argumento.

Exemplo: alterando um valor em uma função

#include <stdio.h>

void alterarValor(int *p) {
    *p = 200;
}

int main() {

    int numero = 10;

    printf("Antes: %d\n", numero);

    alterarValor(&numero);

    printf("Depois: %d\n", numero);

    return 0;
}

Nesse exemplo, a função recebe o endereço da variável. Por meio do ponteiro, consegue modificar seu conteúdo.

Na linguagem C, os argumentos são passados por valor. Ao passar um endereço, a função recebe uma cópia desse endereço e pode acessar a variável original por meio dele.

7. Ponteiros e vetores

Ponteiros e vetores possuem uma relação importante na linguagem C. O nome de um vetor, na maioria das expressões, é convertido em um ponteiro para seu primeiro elemento.

Exemplo:

#include <stdio.h>

int main() {

    int numeros[3] = {10, 20, 30};

    int *p = numeros;

    printf("Primeiro elemento: %d\n", *p);
    printf("Segundo elemento: %d\n", *(p + 1));
    printf("Terceiro elemento: %d\n", *(p + 2));

    return 0;
}

A expressão p + 1 aponta para o próximo elemento do vetor, considerando o tamanho do tipo de dado apontado.

A aritmética de ponteiros será aprofundada em atividades posteriores.

8. Cuidados ao utilizar ponteiros

Ponteiros oferecem grande flexibilidade, mas precisam ser utilizados com atenção.

  • Não utilize um ponteiro sem inicializá-lo.
  • Não acesse endereços inválidos.
  • Não desreferencie um ponteiro NULL.
  • Evite acessar posições fora dos limites de um vetor.
  • Tenha cuidado com a memória alocada dinamicamente.

Um uso incorreto de ponteiros pode provocar falhas durante a execução do programa.

9. Exercícios de fixação

Exercício 1 — Conceitos

Explique, com suas palavras, o que é um ponteiro e qual é sua principal finalidade.

Exercício 2 — Endereço de memória

Crie um programa que declare uma variável inteira, solicite um número ao usuário e apresente:

  • O valor digitado.
  • O endereço de memória da variável.

Exercício 3 — Manipulação de valores

Crie uma variável inteira chamada idade. Utilize um ponteiro para alterar seu valor. Ao final, apresente o valor antes e depois da alteração.

Exercício 4 — Funções e ponteiros

Desenvolva uma função que receba um ponteiro para inteiro e dobre o valor da variável apontada.

Exercício 5 — Ponteiros e vetores

Crie um vetor de cinco números inteiros. Utilize um ponteiro para percorrer o vetor e exibir todos os seus elementos.

10. Conclusão

Os ponteiros permitem trabalhar diretamente com endereços de memória e são fundamentais para compreender diversas estruturas de dados.

Listas encadeadas, filas, pilhas e árvores utilizam ponteiros para conectar e organizar elementos na memória.

Dominar esse conceito é um passo importante para avançar no estudo da linguagem C e das estruturas de dados.
