Estruturas de Dados Lineares

As listas são estruturas de dados utilizadas para armazenar e organizar um conjunto de elementos de maneira sequencial. Elas permitem realizar operações como inserção, remoção, busca e acesso aos dados.

Nesta unidade, estudaremos diferentes formas de implementação de listas utilizando a linguagem C, compreendendo como os elementos são organizados na memória e como os ponteiros permitem construir estruturas dinâmicas.

Objetivos de Aprendizagem

Ao concluir esta unidade, você deverá ser capaz de:

  • Compreender o conceito de listas lineares.
  • Diferenciar listas sequenciais e encadeadas.
  • Implementar operações de inserção e remoção.
  • Realizar buscas e percursos em listas.
  • Utilizar ponteiros para manipular nós dinamicamente.
  • Implementar listas simplesmente encadeadas.
  • Compreender listas duplamente encadeadas e circulares.
  • Gerenciar corretamente a memória alocada.

1. Conceitos de Listas

Uma lista linear é uma estrutura de dados formada por uma sequência de elementos, na qual cada elemento ocupa uma posição lógica dentro da organização.

Diferentemente de um vetor tradicional, uma lista pode ser implementada de diferentes maneiras, permitindo maior flexibilidade na inserção e remoção de elementos.

Principais operações

  • Criação: inicializar uma lista.
  • Inserção: adicionar elementos.
  • Remoção: excluir elementos.
  • Busca: localizar determinado elemento.
  • Percurso: visitar os elementos da lista.
  • Liberação: liberar a memória utilizada.

2. Listas Sequenciais

As listas sequenciais armazenam seus elementos em posições consecutivas da memória, geralmente utilizando vetores.

O acesso aos elementos pode ser realizado por meio dos índices do vetor.

Características

  • Utilizam posições consecutivas de memória.
  • Permitem acesso direto aos elementos por índice.
  • Podem utilizar alocação estática ou dinâmica.
  • A inserção e remoção podem exigir deslocamento de elementos.

Exemplo em C

#include <stdio.h>

#define MAX 5

int main() {

    int lista[MAX];
    int i;

    // Inserção de elementos
    for (i = 0; i < MAX; i++) {
        printf("Digite um numero: ");
        scanf("%d", &lista[i]);
    }

    // Percurso da lista
    printf("\nElementos da lista:\n");

    for (i = 0; i < MAX; i++) {
        printf("%d ", lista[i]);
    }

    return 0;
}

3. Listas Simplesmente Encadeadas

As listas simplesmente encadeadas são estruturas dinâmicas nas quais cada elemento é representado por um nó.

Cada nó armazena um dado e um ponteiro que aponta para o próximo nó da sequência.

Estrutura de um nó

struct No {
    int dado;
    struct No *prox;
};

Características

  • Utilizam alocação dinâmica de memória.
  • Os elementos não precisam ocupar posições consecutivas.
  • Cada nó aponta para o próximo elemento.
  • O último nó aponta para NULL.
  • Permitem inserções e remoções sem deslocar outros elementos.

Representação conceitual

Início
   |
   v
[10 | *] -> [20 | *] -> [30 | NULL]

Operações fundamentais

  • Criação de nós.
  • Inserção no início.
  • Inserção no final.
  • Inserção ordenada.
  • Busca de elementos.
  • Remoção de nós.
  • Liberação completa da lista.

4. Listas Duplamente Encadeadas

Nas listas duplamente encadeadas, cada nó possui dois ponteiros: um aponta para o elemento anterior e outro para o próximo elemento.

Estrutura de um nó

struct No {
    int dado;
    struct No *ant;
    struct No *prox;
};

Representação conceitual

NULL <-> [10] <-> [20] <-> [30] <-> NULL

Características

  • Permitem percorrer a lista nos dois sentidos.
  • Possuem ponteiros para o anterior e o próximo nó.
  • Facilitam determinadas operações de remoção e navegação.
  • Exigem maior gerenciamento de ponteiros.

5. Listas Circulares

Nas listas circulares, o último elemento aponta novamente para o primeiro, formando uma estrutura em formato de ciclo.

Características

  • Não possuem necessariamente um final marcado por NULL.
  • O último nó aponta para o primeiro.
  • Permitem percursos contínuos.
  • Exigem atenção para evitar percursos infinitos.

Representação conceitual

       +-----------------------+
       |                       |
       v                       |
    [10] -> [20] -> [30] ------+

6. Atividades Práticas

Agora é hora de colocar os conhecimentos em prática. Desenvolva os exercícios utilizando a linguagem C.

Exercício 1 – Lista Sequencial

Implemente um programa que utilize um vetor para representar uma lista de números inteiros. O programa deverá permitir:

  • Inserir um elemento.
  • Remover um elemento de determinada posição.
  • Listar todos os elementos.
  • Buscar um número informado pelo usuário.

Exercício 2 – Lista Simplesmente Encadeada

Implemente uma lista simplesmente encadeada utilizando a estrutura struct No e ponteiros.

O programa deverá apresentar um menu com as opções:

  • Inserir elemento no início.
  • Inserir elemento no final.
  • Pesquisar elemento.
  • Remover elemento.
  • Exibir todos os elementos.
  • Encerrar o programa liberando a memória.

Exercício 3 – Comparação de Estruturas

Explique as principais diferenças entre listas sequenciais, simplesmente encadeadas e duplamente encadeadas, considerando armazenamento, acesso, inserção e remoção.

Conclusão

Dominar suas diferentes implementações permite desenvolver programas mais flexíveis, compreender melhor a utilização de ponteiros e gerenciar eficientemente a memória.
