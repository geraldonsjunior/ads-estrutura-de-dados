Início Introdução Ponteiros Vetores e Matrizes

Unidade 3 — Vetores e Matrizes em C

Nesta unidade, estudaremos duas estruturas fundamentais para armazenar e organizar conjuntos de dados: os vetores e as matrizes.

Aprenderemos a declarar essas estruturas, inserir dados pelo teclado, percorrer seus elementos e realizar operações utilizando laços de repetição.

Objetivos de aprendizagem

Ao concluir esta unidade, você deverá ser capaz de:

  • Compreender o conceito de vetor e matriz.
  • Declarar e inicializar vetores em C.
  • Armazenar e acessar elementos de um vetor.
  • Utilizar estruturas de repetição para percorrer vetores.
  • Declarar e manipular matrizes bidimensionais.
  • Desenvolver programas que utilizem vetores e matrizes.

1. O que são vetores?

Um vetor é uma estrutura de dados que permite armazenar vários valores do mesmo tipo utilizando um único nome de variável.

Imagine que precisamos armazenar as notas de cinco alunos. Uma alternativa seria criar cinco variáveis diferentes. Entretanto, podemos utilizar um vetor para organizar essas informações.

Exemplo sem vetor:

float nota1 = 8.0;
float nota2 = 7.5;
float nota3 = 9.0;
float nota4 = 6.5;
float nota5 = 8.5;

Exemplo utilizando vetor:

float notas[5] = {8.0, 7.5, 9.0, 6.5, 8.5};

Observe que utilizamos apenas uma variável chamada notas para armazenar cinco valores.

2. Declarando um vetor em C

Para declarar um vetor, precisamos informar o tipo de dado, o nome da variável e a quantidade de elementos.

Sintaxe:

tipo nome_do_vetor[tamanho];

Exemplos:

int idades[10];

float notas[5];

char letras[20];

No exemplo int idades[10], declaramos um vetor capaz de armazenar dez números inteiros.

Importante: em C, os índices dos vetores começam em zero. 

int numeros[5] = {10, 20, 30, 40, 50};

Indice:       0   1   2   3   4
Elemento:    10  20  30  40  50

Portanto, um vetor com cinco elementos possui índices de 0 até 4.

3. Inicializando um vetor

Podemos atribuir valores ao vetor no momento de sua declaração. 

int numeros[4] = {5, 10, 15, 20};

Também podemos declarar o vetor e inserir os valores posteriormente. 

int numeros[4];

numeros[0] = 5;
numeros[1] = 10;
numeros[2] = 15;
numeros[3] = 20;

Para acessar um elemento, utilizamos o nome do vetor acompanhado de seu índice. 

printf("%d", numeros[0]);

O comando acima apresenta o primeiro elemento do vetor.

4. Percorrendo um vetor com for

Quando precisamos acessar todos os elementos de um vetor, podemos utilizar uma estrutura de repetição.

O comando for é bastante utilizado nessa situação.

Exemplo:

#include <stdio.h>

int main() {

    int numeros[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        printf("%d\n", numeros[i]);
    }

    return 0;
}

Saída:

10
20
30
40
50

A variável i representa o índice utilizado para acessar cada posição do vetor.

5. Inserindo dados pelo teclado

Podemos solicitar que o usuário informe os valores que serão armazenados no vetor.

Exemplo prático: cadastro de notas

#include <stdio.h>

int main() {

    float notas[5];

    for (int i = 0; i < 5; i++) {

        printf("Digite a nota do aluno %d: ", i + 1);
        scanf("%f", &notas[i]);

    }

    printf("\nNotas cadastradas:\n");

    for (int i = 0; i < 5; i++) {

        printf("Aluno %d: %.2f\n", i + 1, notas[i]);

    }

    return 0;
}

Nesse programa, utilizamos um primeiro laço para receber as notas e um segundo laço para apresentar os valores armazenados.

6. Realizando operações com vetores

Além de armazenar informações, podemos realizar cálculos utilizando os elementos de um vetor.

Exemplo: calcular a média de cinco notas

#include <stdio.h>

int main() {

    float notas[5];
    float soma = 0;
    float media;

    for (int i = 0; i < 5; i++) {

        printf("Digite a nota %d: ", i + 1);
        scanf("%f", &notas[i]);

        soma += notas[i];
    }

    media = soma / 5;

    printf("\nMedia da turma: %.2f\n", media);

    return 0;
}

A variável soma acumula os valores informados. Ao final, dividimos o total pela quantidade de notas para obter a média.

7. O que são matrizes?

Uma matriz é uma estrutura de dados que permite armazenar valores do mesmo tipo organizados em duas ou mais dimensões.

Nesta unidade, trabalharemos principalmente com matrizes bidimensionais, organizadas em linhas e colunas.

Podemos imaginar uma matriz como uma tabela.

Exemplo:

int numeros[2][3];

Essa declaração cria uma matriz com duas linhas e três colunas, totalizando seis elementos.

Representação:

        Colunas
          0   1   2

Linha 0   10  20  30
Linha 1   40  50  60

Para acessar um elemento, utilizamos dois índices: o primeiro representa a linha e o segundo representa a coluna.

8. Declarando e inicializando matrizes

A declaração de uma matriz bidimensional utiliza dois tamanhos: quantidade de linhas e quantidade de colunas.

Sintaxe:

tipo nome[linhas][colunas];

Exemplo:

int matriz[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
};

Para acessar o número 50, utilizamos: 

matriz[1][1]

Lembre-se: os índices começam em zero.

9. Percorrendo uma matriz

Para percorrer uma matriz, geralmente utilizamos dois laços de repetição: um para as linhas e outro para as colunas.

Exemplo:

#include <stdio.h>

int main() {

    int matriz[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    for (int i = 0; i < 2; i++) {

        for (int j = 0; j < 3; j++) {

            printf("%d ", matriz[i][j]);

        }

        printf("\n");
    }

    return 0;
}

Saída:

10 20 30
40 50 60

O primeiro laço controla as linhas e o segundo controla as colunas.

10. Inserindo dados em uma matriz

Assim como nos vetores, podemos solicitar que o usuário informe os valores de uma matriz.

Exemplo: preenchendo uma matriz 2 × 3

#include <stdio.h>

int main() {

    int matriz[2][3];

    for (int i = 0; i < 2; i++) {

        for (int j = 0; j < 3; j++) {

            printf("Digite o valor da linha %d e coluna %d: ",
                   i + 1, j + 1);

            scanf("%d", &matriz[i][j]);

        }
    }

    printf("\nValores da matriz:\n");

    for (int i = 0; i < 2; i++) {

        for (int j = 0; j < 3; j++) {

            printf("%d\t", matriz[i][j]);

        }

        printf("\n");
    }

    return 0;
}

Nesse exemplo, utilizamos dois laços para preencher a matriz e outros dois para apresentar os valores.

11. Diferenças entre vetores e matrizes

Embora sejam estruturas semelhantes, existem diferenças importantes entre vetores e matrizes.

  • Vetor: organiza os elementos em uma única dimensão.
  • Matriz: organiza os elementos em linhas e colunas.
  • Vetor: utiliza um índice para acessar cada elemento.
  • Matriz: utiliza dois índices para acessar cada elemento bidimensional.

12. Cuidados importantes

  • Os índices de vetores e matrizes começam em zero.
  • Não acesse posições fora dos limites declarados.
  • Verifique se os laços utilizam os limites corretos.
  • Utilize o tipo de dado adequado para cada informação.
  • Inicialize as variáveis utilizadas nos cálculos.

Em C, acessar posições fora dos limites de um vetor ou matriz provoca comportamento indefinido.

13. Exercícios de fixação

Exercício 1 — Cadastro de números

Desenvolva um programa que solicite ao usuário cinco números inteiros, armazene-os em um vetor e apresente todos os valores cadastrados.

Exercício 2 — Soma dos elementos

Crie um vetor com dez números inteiros. Solicite os valores pelo teclado e calcule a soma de todos os elementos.

Exercício 3 — Média de notas

Desenvolva um programa que armazene as notas de cinco alunos em um vetor e calcule a média geral da turma.

Exercício 4 — Maior e menor valor

Crie um vetor de dez números inteiros. Ao final, apresente o maior e o menor valor armazenado.

Exercício 5 — Cadastro de temperaturas

Armazene as temperaturas registradas durante sete dias em um vetor. Calcule a média e apresente os dias em que a temperatura ficou acima da média.

Exercício 6 — Matriz 3 × 3

Desenvolva um programa que solicite nove números inteiros, armazene-os em uma matriz 3 × 3 e apresente os valores organizados em linhas e colunas.

Exercício 7 — Soma da matriz

Crie uma matriz 3 × 3, solicite os valores pelo teclado e calcule a soma de todos os seus elementos.

Exercício 8 — Diagonal principal

Desenvolva um programa que leia uma matriz 3 × 3 e apresente os elementos da diagonal principal.

14. Desafio prático

Sistema de notas de uma turma

Desenvolva um programa em C para cadastrar as notas de cinco alunos em duas avaliações.

O programa deverá:

  1. Utilizar uma matriz para armazenar as notas.
  2. Solicitar as duas notas de cada aluno.
  3. Calcular a média individual de cada aluno.
  4. Apresentar o resultado de cada estudante.
  5. Informar quantos alunos foram aprovados.

Considere a média 7,0 como nota mínima para aprovação.

Utilize estruturas de repetição para preencher e percorrer a matriz.

15. Conclusão

Vetores e matrizes são estruturas fundamentais para armazenar e organizar conjuntos de informações.

Compreender essas estruturas é importante para desenvolver programas mais organizados e resolver problemas que envolvem grandes quantidades de dados.

Esses conhecimentos também serão utilizados no estudo de listas sequenciais, listas encadeadas, pilhas e filas.
